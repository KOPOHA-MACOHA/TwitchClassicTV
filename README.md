# Twitch Classic TV

Русскоязычный форк [SmartTwitchTV](https://github.com/fgl27/SmartTwitchTV) для Android TV / Google TV с интерфейсом в стиле Twitch и управлением пультом.

**[Скачать APK из Releases](https://github.com/KOPOHA-MACOHA/TwitchClassicTV/releases)** · **[Ошибки и предложения](https://github.com/KOPOHA-MACOHA/TwitchClassicTV/issues)**

Приложение устанавливается как **Twitch Classic** (`org.tvmod.classic`), отдельно от официального Twitch и исходного клиента. В 0.14 кнопка «Проверить обновления» находится в основном списке настроек; при запуске приложение само предлагает новую версию. Обновления устанавливаются поверх предыдущих сборок с сохранением данных, если сохранён ключ подписи.

## Возможности

- Верхние вкладки, карточки с закруглёнными превью, единый экран подписок: эфиры сверху, офлайн-каналы ниже; страницы каналов с видео и клипами.
- Вход через QR-код или код активации, настройки с навигацией пультом, шрифты Inter/Roobert.
- Качество по умолчанию, аккуратный оверлей, один ряд кнопок и отдельная полоса перемотки. Чат поверх видео, рядом с ним или скрытый.
- 7TV / BTTV / FFZ, zero-width композиции и модификаторы, цвета ников из Twitch с отключаемым осветлением тёмных цветов, настройки чата, ограниченные превью прямых ссылок на картинки с новой строки.
- Мультистрим: четыре окна, выбор эфиров из подписок или общего списка, замена, звук, основное окно, удаление, выбор чата и отдельный предел качества. «Вверх» открывает панель выбора.
- Дополнительное число в скобках — подключённые к чату пользователи, включая ботов и пользователей без видео. Это **не число подтверждённых зрителей**; опция отключается в настройках чата.
- Проверка новых APK через Releases этого репозитория. Установку подтверждает системный установщик Android.

Отправка времени просмотра и получение бонусных баллов работают через существующие API Twitch. Зачёт часов, стриков и итогов года сервером не гарантирован. Переход по рейдам не означает серверное участие в рейде или начисление рейдового бонуса. Подробности: [учёт просмотра](research/watch-accounting.md).

## Исходники и сборка

Исходная точка: upstream `7ca7b76249b4c2a6b2f44932641f49894410c99a`. Текущие изменения до 0.11 сохранены отдельным импортирующим коммитом; дальнейшие исправления идут отдельными коммитами.

```sh
python fork-build/bootstrap.py
python fork-build/build.py
python fork-build/validate.py
```

Нужны Python 3.11+, Java 21 и `curl`. Проверка APK требует `pip install androguard==4.1.3`. Скрипт загрузки проверяет SHA-256 нативной базы 3.0.379, Morphe 1.20.0 и Kotlin 2.4.0. Сборка APK содержит соответствующие исходники в `assets/classic-source.zip`.

Релизные сборки используют **прежний приватный ключ**, а не новый автоматически созданный. Настройка GitHub Actions и обновлений: [docs/RELEASES.md](docs/RELEASES.md). Результаты компиляции, APK, ключи и логи в исходники не включаются.

## Проверки

```sh
npm --prefix tests install --ignore-scripts
cd tests && npx playwright-core install --with-deps chromium
cd .. && npm --prefix tests test
```

Браузерные проверки запускают реальный интерфейс с тестовыми ответами Twitch и имитацией Android-моста: навигация, авторизация, старт эфира, мультистрим, счётчики, смайлы, настройки и обновления. Они не заменяют проверку декодирования видео и работы пульта на физическом телевизоре.

Нативный плеер остаётся побайтно тем же, что в проверенной пользователем сборке 0.4. Он основан на upstream Media3; UI поставляется локально внутри APK. Полная история исправлений и ограничения: [fork-build/README.md](fork-build/README.md). Оригинальная документация: [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md).
