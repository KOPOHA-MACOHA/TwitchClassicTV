Исправление регрессии мультистрима в 0.14. При входе снова применяется стандартный профиль малых окон, использовавшийся в 0.13. Неограниченное качество больше не включается автоматически; повышенный предел выбирается вручную. После обновления сохранённый режим 0.14 один раз сбрасывается к стандартному.

Если нативный плеер отвергает дополнительный поток с повышенным пределом, выполняется только один повторный запуск со стандартным профилем. При повторной ошибке её код показывается сверху панели мультистрима; исправные окна сохраняются. Добавлена проверка именно отказа декодера после вызова запуска, а не только факта вызова StartMultiStream.

Исправлено автоматическое выключение чата при входе с уже видимым чатом. Возможности 0.14 — новый попап обновления, кнопка проверки, проверка при запуске, выбор чата и картинки с новой строки — сохранены.

Проверки выполнялись в браузере с имитацией нативных событий. Физический телевизор для проверки недоступен. Нативные DEX и ключ подписи не менялись.
