Отчёт о синхронизации просмотра по QR-коду. Его можно открыть в настройках синхронизации и считать с телевизора как текст. В отчёт входят последние результаты за текущий сеанс, включая чтение и сохранение позиции, историю, баллы и рейды. Учётные данные, идентификаторы, названия каналов и ссылки в отчёт не включаются.

Если Twitch отклоняет общий запрос истории при открытии записи, приложение пробует получить позицию напрямую для этой записи в пределах того же времени ожидания. Запоздавший ответ на рейд не переключает эфир после ручной смены канала.
