История Twitch и видимый блок продолжения просмотра.

- «Продолжить просмотр» в «Подписках» больше не исчезает при пустом ответе Twitch. Если записей нет или загрузка не удалась, видны результат и кнопка обновления. Долгое OK на обычных карточках по-прежнему обновляет подписки.
- История загружается запросом, соответствующим официальному ТВ-клиенту (20 записей), и отдельным расширенным запросом аккаунта (до 1000, с резервным ограничением 100). Результаты объединяются по ID и времени изменения, без ограничения только подписанными каналами.
- Записи с неизвестной длительностью и ещё записывающиеся эфиры не отбрасываются из продолжения. Поддерживается резервная позиция video.self.viewingHistory.
- «Вся доступная история Twitch» открывает историю записей, куда импортируются также просмотренные до конца видео. Локальные записи сохраняются; повторная загрузка не создаёт дубликатов. Скрытие из ряда продолжения действует только на этом ТВ.
- Пустой список и ошибка разделены; результаты загрузки сохраняются для текущего аккаунта. Чужой ответ и поздние ответы отменённого запроса не применяются.

Twitch не предоставляет курсор для viewedVideos: это доступное серверное окно истории, а не гарантированный архив за всё время. Просмотренные прямые эфиры появятся, если Twitch вернул их сохранённые записи с позицией. Удалённые/недоступные записи восстановить нельзя. Учёт стриков и итогов года этим изменением не реализуется.

Проверены браузерные сценарии с имитацией ответов сервера и актуальная схема GraphQL без авторизации. Полное совпадение с историей реального мобильного аккаунта требует проверки на ТВ. Подпись приложения и нативные DEX не менялись.
