Исправлено подключение эфиров в мультистриме: клиент сохраняет URL запроса отдельно для каждого запроса и слота, поскольку Android 3.0.379 не возвращает URL в ответе. Ошибка доступа от Twitch теперь завершает попытку сразу, сохраняя прежнюю трансляцию, вместо ожидания тайм-аута. Исправлено также восстановление URL в обычном и синхронном пути воспроизведения. Нативный плеер и подпись APK сохранены.

Модифицированные и zero-width эмоуты получили корректные границы: широкий смайл резервирует всю ширину, наложения остаются внутри своей композиции, поворот и тряска не рисуются на соседних словах и смайлах. Проверены цепочки эмоутов в середине сообщения и перенос строк.

Добавлена настройка «Осветлять тёмные ники» (включена по умолчанию). Тёмные цвета осветляются с сохранением оттенка; исходный цвет Twitch сохранён и восстанавливается при отключении настройки. Светлые цвета не меняются.

Проверки используют фактический формат ответа нативного моста без URL, проверяют одновременные запросы в обратном порядке и URL, переданный в StartMultiStream / StartAuto. Дополнительно проверяются границы эмоутов в разных фазах анимации и читаемость ников. Физический телевизор для проверки недоступен.
