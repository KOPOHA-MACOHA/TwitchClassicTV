# Twitch branding assets

The Twitch Glitch vector is sourced from Simple Icons: https://cdn.simpleicons.org/twitch/FFFFFF (retrieved 2026-11-14). Simple Icons distributes its icon collection under CC0-1.0; Twitch branding remains owned by Twitch. See https://github.com/simple-icons/simple-icons and https://www.twitch.tv/p/en/legal/trademark/ . The custom launcher banner and splash layout are rendered by fork-build/render-branding.cjs using this bundled vector, without remote requests. The app remains an unofficial client named Twitch Classic.
