# Interface fonts

The Inter WOFF2 subsets are the same variable font files referenced by Twitch core CSS fetched on 2026-11-15. Sources and SHA-256 hashes are in sources.json. Embedded font metadata identifies Copyright 2020 The Inter Project Authors and SIL OFL; the project license is bundled in Inter-LICENSE.txt. All Inter weights and Cyrillic/Latin glyphs work from bundled assets without network access.

Roobert headline faces are referenced from their official Twitch CDN URLs in styles/fonts.css. They are not redistributed in this APK. font-display: optional and bundled Inter fallback keep headings readable when the CDN is unavailable, including Cyrillic glyphs absent from Roobert.
